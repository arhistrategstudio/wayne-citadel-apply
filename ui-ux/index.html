What we are building

Problem

Infrastructure changes submitted through GitHub pull requests can silently introduce security risks: widened IAM permissions, public exposure, destructive replacements. Reviewers rarely have time to read a full Terraform plan.

Constraint

Explain only the change, never scan the whole state. The AI must never decide what a finding is or how severe it is. Those decisions stay with deterministic logic. Nothing in the output may be invented.

Decision

Detection is separate from explanation. A deterministic analyzer produces findings as facts. A grounded language-model layer turns them into a readable impact explanation, validated against the input facts before it is published to the pull request as a comment and as SARIF.
